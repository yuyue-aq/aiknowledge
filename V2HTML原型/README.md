# 知溯 V2 HTML 原型

直接打开 **01-核心业务.html**。顶部导航可以切换五组页面；每组卡片点击「查看」打开完整交互预览，可切换桌面与手机布局。

| 文件 | 场景数 | 内容 |
| --- | ---: | --- |
| 01-核心业务.html | 6 | 空间、资料、独立检索、问答与引用 |
| 02-评测与复测.html | 6 | 测试题、相关证据、运行、人工评分、对比 |
| 03-公开分享.html | 6 | 开放分类、分享链接与访客状态 |
| 04-反馈与异常状态.html | 9 | 反馈、修复、空状态、失败、范围变化 |
| 05-后续扩展.html | 6 | P1 / P2 的高级检索与回归概念 |

全部为合成数据与本地交互，上传、保存、删除、公开发布均不作用于真实业务。输入问题会展示固定样例回答，不计算真实向量，也不请求模型。刷新页面会重置演示状态。

五个 HTML 各自内嵌样式、脚本与数据，可单独复制使用。共享维护源位于 assets，运行 `python build.py` 重新生成，避免分别修改五份 HTML。

产品依据：上级目录的 V2需求分析文档、V2方案设计文档，以及已确认的 V2UI原型草图与风格方案。视觉规范继承 V1 的 aiknowledge_frontend/DESIGN.md 与 src/app.scss。

设计参考：[Linear 界面改版](https://linear.app/now/how-we-redesigned-the-linear-ui) 的导航与信息层级；[Dify 知识库教程](https://docs.dify.ai/en/learn/tutorials/customer-service-bot) 的资料和检索任务布局。均保留 V1 色彩与中文产品表达。
